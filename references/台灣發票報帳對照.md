# 台灣常見發票/單據 → 報帳金額對照

機器人辨識單據時,「報帳金額」要抓哪一欄,依單據類型不同。**黃金通則:報帳金額 = 含稅總額(總計/合計)。**
唯一陷阱是「有把未稅與含稅分開列」的格式(三聯式),要抓含稅那個,不要抓未稅銷售額。

| 類型 | 長相特徵 | 報帳金額抓哪欄 | 是否電子發票 |
|------|---------|---------------|-------------|
| **三聯式統一發票** | 有「銷售額」「營業稅」「總計」**三個金額**;常手寫;第三聯=扣抵聯 | **總計(含稅)** ⚠️ 不是未稅銷售額 | 否(紙本) |
| **二聯式統一發票** | 多為收銀機列印,品項下方一個「總計/合計」(已內含稅) | 總計/合計(該單一金額即含稅) | 否(紙本) |
| **收銀機統一發票** | 商店收銀機印的,有發票號碼、品項、總計 | 總計 | 否 |
| **電子發票證明聯** | 印有「電子發票證明聯」字樣 + 隨機碼/載具/QR;有「應稅銷售額」「總計」 | 總計(含稅) | **是**(明確有「電子發票」字樣) |
| **一般收據/估價單** | 無發票號碼的普通收據(影印、雜支、無統編商家) | 單一金額(通常已是實付額) | 否 |
| **計程車/停車收據** | 車資/停車費單一金額 | 該金額 | 否 |
| **高鐵/台鐵/捷運車票** | 印有票價 | 票價 | 否 |
| **機票/登機證** | 票價(電子機票收據可能列稅、燃油費,以總額為準) | 含稅總額 | 視單據(多為否) |

## 實作對應(本機器人)
- OCR prompt 已內建通則:**金額一律取含稅總額;三聯式取「總計」、不要取未稅銷售額**,
  並把子表格的「單價」與「小計」都填成總計值(數量 1 的情況)。
- 是否電子發票:交通票券(高鐵/捷運/計程車/飛機)一律「否」;其餘只在單據明確出現
  「電子發票」字樣才算「是」(故電子發票證明聯=是,紙本統一發票=否)。
- 金額多為手寫,prompt 已提示逐位小心(例:台灣手寫「9」易被誤判)。

## 範例(使用者教過的)
三聯式統一發票:銷售額 6,190 + 營業稅 310 = **總計 6,500** → 報帳金額 = **6,500**。
